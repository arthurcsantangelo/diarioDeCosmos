Clone o repositório:

git clone URL_DO_SEU_REPOSITORIO

Entre na pasta:

cd diarioDeCosmos

Instale as dependências:

npm install

Crie um arquivo .env na raiz do projeto e adicione sua chave:

NASA_API_KEY=sua_chave_aqui

Inicie o servidor:

npm start

Acesse no navegador o endereço informado pelo servidor.
